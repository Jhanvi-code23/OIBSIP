Login Authentication System

A secure and responsive Login Authentication System built using HTML, CSS, and Vanilla JavaScript. The application allows users to register, log in securely, and access a protected dashboard while ensuring password security through SHA-256 hashing. It also integrates authentication with the CheckMate To-Do List, providing every user with their own personalized workspace.

This project was created as part of Level 2 – Task 4 of the Oasis Infobyte Web Development Internship.
