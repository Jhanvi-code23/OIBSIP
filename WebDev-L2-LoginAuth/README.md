# Login Authentication System

A secure and responsive Login Authentication System built using HTML, CSS, and Vanilla JavaScript. The application enables users to register, log in securely, and access a protected dashboard while ensuring password security through SHA-256 hashing. It is integrated with the CheckMate To-Do List, providing every registered user with their own personalized workspace and session.

This project was created as part of **Level 2 – Task 4** of the **Oasis Infobyte Web Development Internship**.

- User Registration
- Secure Login Authentication
- Password Hashing using SHA-256
- Password Validation
- Duplicate Username & Email Detection
- Protected Dashboard
- Session Management
- Logout Functionality
- Show/Hide Password Option
- User-specific To-Do Lists
- Local Storage Support
- Responsive Dark-Themed UI
